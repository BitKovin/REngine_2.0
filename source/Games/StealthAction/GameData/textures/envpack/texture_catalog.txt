============================================================
Textures: 293  (288 JPG opaque, 5 PNG with alpha)
Style: old European village with a gothic church; photo-derived, muted, grimy, soft, no outlines, no text/logos.
Scale: 64 px = 1 m. A 256x256 texture covers 4 m x 4 m. Real-world size is given for every entry.
Resolution: mixed pack. 214 textures are the 1x file, 79 are the 2x file (twice the pixels), chosen so every texture has the right perceived size next to a 1.8 m person. The editor takes the size from the pixels at 64 px = 1 m, so the size column and real size column below are what the editor shows.
Tiling: every texture repeats seamlessly left-right and top-bottom. Facade textures repeat their windows/doors when tiled.
Filename: <name>.jpg (opaque) or <name>.png (transparent cutout). The name is the texture id.

HOW TO SEARCH (for AI models)
- Match the wanted surface/material first (category + name), then refine with tags (colour, condition, features).
- Names read as <type>_<details>: e.g. facade_* = wall with windows/doors, plaster_*/concrete_* = blank wall filler, *_small / *_strip = reduced tiles.
- Condition words: clean, weathered, grimy, mossy, soot, stained, cracked, decayed/ruin, ivy/overgrown.
- Texture families have close variants (e.g. brick_dark_brown_fine / _dirty). Pick by tone/colour/condition tags.
- *_masked textures are PNG cutouts: use for fences, foliage, hedges, ladders, lattice; the rest are opaque.
- Facade sets that share a wall style: french_half_timber_* (gable, plain, braces, window), church_wall_* (plain, door, windows, shutters, cracked), facade_cracked_plaster_*, exterior_wall_*_shutters_open/closed.
